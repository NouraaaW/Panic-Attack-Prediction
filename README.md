# Panic Attack Prediction 🧠

## 📌 Project Overview
Mental health is a critical aspect of overall well-being. This project leverages **Data Mining** techniques to analyze panic attack data, identify risk factors, and predict an individual's susceptibility to panic attacks.

The goal is to provide a predictive model that can aid in early intervention and better understanding of the triggers associated with panic disorders.

## 🔄 Data Mining Process
The project follows a structured data mining pipeline:
1.  **Data Preprocessing:** Cleaning data, handling missing values, and encoding categorical variables.
2.  **Exploratory Data Analysis (EDA):** Visualizing correlations and distribution of risk factors.
3.  **Model Implementation:** Applying various classification algorithms.
4.  **Evaluation:** Comparing models based on Accuracy, Precision, Recall, and F1-Score.
